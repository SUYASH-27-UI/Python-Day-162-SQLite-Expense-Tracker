# SQLite Expense Tracker – Python Day 162

## Description
A Python application that stores and manages personal expenses using an SQLite database.

## Features
- Add new expenses
- View all expense records
- Calculate total expenses
- Generate category-wise spending summaries
- Search expenses by category
- Automatically create and maintain a database

## Technologies
- Python
- SQLite
- sqlite3 Module

## Files
- `expense_tracker.py`
- `expenses.db` – generated automatically

## How to Run
```bash
python expense_tracker.py
```

## Concepts Used
SQLite Database, SQL Queries, CRUD Basics, Database Connections, Exception Handling and Data Aggregation.
